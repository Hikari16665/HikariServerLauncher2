# Contributing

## Commit Guidelines

### Allowed Commit Types

- **AI-authored commits**: AI tools may write and commit code changes. Commit messages for these must be written by a human -- describe what changed and why in your own words.
- **Format-only commits**: Changes limited to formatting, whitespace, lint fixes, or import ordering are welcome. Mark these with a `[format]` tag prefix in the commit message.

### Commit Message Rules

- Commit messages must be written by a human. Do not paste AI-generated commit messages.
- Messages should be concise and describe the motivation behind the change, not a list of files touched.
- Write messages in the language that matches the codebase (Chinese or English, depending on context).

### Why

AI-generated commit messages lack the judgment and intent signals that a human-written message carries. A reader should be able to tell that a real person reviewed the diff and understood why it mattered.
